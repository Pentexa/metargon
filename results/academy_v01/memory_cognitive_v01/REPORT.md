## Protocol

- **Training budget / matched exposure**: 160 episodes per train seed, seeds
  `{20261107, 20261108}` (2 seeds), shared training pool stream; the same
  stream is consumed by every variant.
- **Evaluation**: matched streams per seed; paired per-config bootstrap
  (2000 resamples, 95% CI); convention `candidate − baseline` (positive =
  candidate better). Frozen cells assert no learning leaked (`generated`,
  `step`, agent `steps` unchanged).
- **Task families**:
  - *classic* (compatible): held-out test pool, eval seed 20261108;
  - *conflict* (conflicting rules): flipped-polarity pool built from core
    rules on the same observable contexts, eval seed 20261108+2
    (isolation asserted against train/val/test/ood);
  - *noisy*: same configs under observational noise q=0.2, eval seed
    20261108+3.
- **Regimes measured separately**: frozen zero-shot transfer; adaptive
  transfer (learning enabled); retention (frozen substrate, mid-training vs
  final state, substrate 20261107+31); repeated learning A/B/A (train A →
  frozen-eval A′ → train conflicting B → frozen-eval B → retrain A →
  frozen-eval A″; focus 20261107+47).
- **Controls**: fresh (untrained), original (existing memory), memory_wiped
  (memory-muted, wipe asserted), epoch (v0.7), epoch_reset (v0.7 +
  per-episode probe reset), cognitive (proposed), cognitive_shuffled
  (negative control; shuffle asserted).
- **Reproducibility**: canonical config ordering (hash-seed independent,
  verified across PYTHONHASHSEED ∈ {0,1,7}); fresh-control cache
  fingerprint-keyed; full run repeated twice under hash 0 with identical
  numbers.

## 5. Verdict

**Negative result for the proposed reliability-ranking layer.**

- `cognitive` matches `original` on classic frozen (Δ≈0) while the v0.7
  baselines gain +0.19; it shows non-significant gains on conflict/noisy
  frozen vs original, but is **weaker than `epoch_reset` on adaptive
  transfer** (classic 0.578 vs 0.664; conflict 0.431 vs 0.556) and on
  retention mean (+0.062 vs −0.125).
- **Repeated learning is the strongest regression**: `cognitive` is the
  only variant that fails to recover the original rule family after
  conflicting training (A2 collapses to 0.125; A2−A1 = −0.500). This
  replicates across all runs.
- Diagnostic (probe relevance, classic frozen): `cognitive` makes
  hypothesis probes far more relevant (65.8% partial vs 2.4% for
  `epoch_reset`) but starves exact novel-single discovery (32 probes vs
  328; those novel singles are 100% exact). The layer optimizes the wrong
  currency: partial cross-task memories do not open doors.
- Controls behave as designed: `memory_wiped ≡ original` under frozen
  (memory unused by vanilla agent) but differs adaptively; `cognitive_-
  shuffledled ≠ cognitive` in every mode → content matters, and the
  randomized-association control is not systematically worse.

The proposed layer is **off by default**, preserves historical evidence
(no destruction; revival via support verified by unit tests), and keeps
legacy checkpoint compatibility. No merge is requested; the current best
configuration remains `epoch_reset` (v0.7 episode-scoped evidence +
per-episode probe reset). Suggested next step: apply reliability as a
threshold *filter* on hypothesis reuse rather than a global re-ranking.
